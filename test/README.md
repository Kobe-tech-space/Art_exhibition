# 攀登之路 - 本地部署指南

## 游戏介绍

这是一个简单的平台跳跃游戏，玩家需要控制小人向上攀登，收集5把钥匙通关。

## 操作说明

- **跳跃**: W 键 / ↑ 方向键 / 空格键
- **向左移动**: A 键 / ← 方向键
- **向右移动**: D 键 / → 方向键
- **快速下落**: S 键 / ↓ 方向键

## 本地运行方法

### 方法一：使用 Python（推荐）

1. **打开命令提示符**
   - 按下键盘上的 `Win + R`
   - 输入 `cmd` 并按回车

2. **进入游戏文件夹**
   - 输入 `cd G:\artwork\test` 并按回车

3. **启动服务器**
   - 输入 `python -m http.server 8000` 并按回车

4. **打开游戏**
   - 打开浏览器（如 Chrome、Edge）
   - 在地址栏输入 `http://localhost:8000` 并按回车

### 方法二：直接打开 HTML 文件

1. **找到游戏文件**
   - 打开文件资源管理器
   - 进入 `G:\artwork\test` 文件夹

2. **打开游戏**
   - 双击 `index.html` 文件
   - 游戏会在浏览器中打开

### 方法三：使用 VS Code（如果你有安装）

1. **打开项目**
   - 打开 VS Code
   - 点击"打开文件夹"，选择 `G:\artwork\test`

2. **安装扩展**
   - 在扩展商店搜索 "Live Server" 并安装

3. **启动服务器**
   - 右键点击 `index.html` 文件
   - 选择 "Open with Live Server"

## 游戏玩法

1. 点击"开始攀登"按钮开始游戏
2. 使用方向键或 WASD 控制小人移动和跳跃
3. 向上攀登，躲避红色炸弹
4. 收集黄色加速道具可以跳得更高
5. 到达每关顶部收集钥匙
6. 收集全部5把钥匙即可通关

## 注意事项

- 确保所有文件都在正确的位置
- 如果图片显示不出来，请检查文件路径是否正确
- 游戏需要在现代浏览器中运行（Chrome、Firefox、Edge等）

## 常见问题

**Q: 游戏打不开怎么办？**

A: 请确保你按照上面的步骤操作。如果还是不行，可以尝试：
1. 检查网络连接
2. 刷新浏览器页面
3. 关闭浏览器重新打开

**Q: 游戏画面卡住了？**

A: 按 F5 刷新页面即可。

**Q: 没有声音？**

A: 这个游戏目前没有背景音乐和音效。
